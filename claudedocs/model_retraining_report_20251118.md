## 3. 과적합(Overfitting) 분석

### 3.1 Train-Test 성능 격차 분석

| 모델 | Train R² | Test R² | 격차 | 과적합 수준 |
|------|----------|---------|------|-------------|
| Linear Regression | 0.364 | **0.375** | **-0.011** | ✅ **없음** (Test > Train) |
| Ridge Regression | 0.364 | **0.375** | **-0.011** | ✅ **없음** (Test > Train) |
| Weighted Ensemble | 0.677 | 0.602 | **+0.075** | ⚠️ **경미** |

### 3.2 MAPE 기준 분석

| 모델 | Train MAPE | Test MAPE | 격차 | 평가 |
|------|------------|-----------|------|------|
| Linear Regression | 0.462% | 0.451% | -0.011%p | ✅ 일반화 우수 |
| Ridge Regression | 0.462% | 0.451% | -0.011%p | ✅ 일반화 우수 |
| Weighted Ensemble | 0.256% | 0.276% | **+0.020%p** | ✅ 허용 범위 |

### 3.3 과적합 평가 기준

**일반적인 기준**:
- **R² 격차 < 0.05**: 과적합 없음 ✅
- **R² 격차 0.05-0.15**: 경미한 과적합, 허용 가능 ⚠️
- **R² 격차 > 0.15**: 심각한 과적합, 조치 필요 ❌

**현재 모델 평가**:
- **Linear/Ridge**: R² 격차 -0.011 → ✅ **과적합 없음** (오히려 Test 성능이 더 좋음)
- **Ensemble**: R² 격차 +0.075 → ⚠️ **경미한 과적합** (허용 범위 내)

### 3.4 과적합 우려에 대한 답변

**Q: MAPE가 53% → 0.28%로 개선된 것이 과적합 아닌가?**

**A: 과적합이 아닌 다음 이유들로 설명됩니다:**

1. **학습 데이터 2.9배 증가**
   - 이전: 2,520개 → 재학습: 7,405개
   - 더 많은 데이터로 실제 패턴을 충분히 학습 가능

2. **Test 성능도 동일하게 향상**
   - 이전 Ensemble Test R²: 0.106
   - 재학습 Ensemble Test R²: 0.602
   - Train과 Test 모두 향상 → 일반화 능력 개선

3. **Linear/Ridge 모델에서 과적합 없음**
   - Test R² > Train R² (0.375 > 0.364)
   - 가장 단순한 모델에서도 큰 성능 향상 확인
   - 데이터 품질 및 대표성 향상의 증거

4. **Ensemble의 R² 격차 0.075는 허용 범위**
   - 일반적으로 0.05-0.15는 경미한 수준
   - MAPE 격차 0.02%p로 실용적으로 문제없음

5. **이전 모델의 낮은 성능 원인**
   - 학습 데이터 부족 (2,520개)
   - 데이터 대표성 부족
   - 재학습으로 충분한 데이터 확보

**결론**: ✅ **과적합 아님. 데이터 증가와 품질 향상으로 인한 정상적인 성능 개선**
