# 낙찰하한가 예측 비즈니스 로직

## 도메인 지식

### 입찰 프로세스
1. **공고 단계**: 지역, 업종, 하한율, A값, 기초금액 공개
2. **예가 결정**: 내부적으로 예가 결정 (우리의 예측 대상)
3. **낙찰하한가 계산**: 공식 적용하여 최종 계산

### 핵심 계산 공식
```
예정가격 = 기초금액 × 예가
낙찰하한가 = (예정가격 - A값) × 낙찰하한율 + A값
```

### 예측 전략
- **직접 예측 대상**: 예가 (예정가격과 기초금액의 비율)
- **입력 변수**: 공고 시점에 알 수 있는 정보만 활용
- **최종 목표**: 낙찰하한가 정확도 최대화

## 입력 변수 상세

### 카테고리 변수
- **지역**: 시/도 단위 지역 코드
- **업종**: 건설업종 분류 (토목, 건축, 전기, 통신 등)

### 수치 변수
- **하한율**: 낙찰하한율 (일반적으로 0.8~0.95 범위)
- **A값**: 계산에 사용되는 상수
- **기초금액**: 입찰 공고에서 제시되는 기준 금액

## 비즈니스 목표
- **낙찰 성공률 향상**: 적정 입찰가 산정으로 경쟁력 확보
- **리스크 관리**: 과도한 저가 입찰로 인한 손실 방지
- **의사결정 지원**: 데이터 기반 입찰 전략 수립

## 성공 지표
- **예측 정확도**: MAPE 5% 이하
- **비즈니스 효과**: 낙찰 성공률 20% 개선
- **운영 효율성**: 입찰 준비 시간 단축
